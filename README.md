# Idle Reef - Steam item icons

Icons for the Steam Inventory items of Idle Reef (app 5188560), served by GitHub Pages at
https://erdemblkc.github.io/idle-reef-icons/

- `{itemdefid}.png` - 200 x 200, `icon_url`
- `{itemdefid}_large.png` - 2048 x 2048, `icon_url_large`

2001-2050 fish, 1001-1008 eggs, 4001-4011 crabs, 4100 crab chest.

Steam downloads and caches these files: never rename or delete them once the game is live.
Made by Unity's "Idle Reef > Steam ikonlarini uret" menu (steam/icons in the game project).
